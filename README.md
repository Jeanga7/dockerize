## DESCRIPTION

__Le projet ASCII Art Web est un site web interactif qui permet aux utilisateurs de convertir du texte en art ASCII. Voici un résumé des fonctionnalités  :__

### Fonctionnalités :

   - __Interface Utilisateur__ :
       - Les utilisateurs peuvent entrer du texte dans un champ de texte.
      -  Ils peuvent choisir parmi différents styles de bannière ASCII (standard, shadow, thinkertoy).
      -  L'utilisateur peut soumettre le formulaire pour générer de l'art ASCII basé sur le texte et le style de bannière sélectionnés.

   - Conversion ASCII :
       - Le texte saisi par l'utilisateur est converti en art ASCII en utilisant le style de bannière choisi.
       - L'art ASCII généré est affiché à l'utilisateur.

   - Animation de Chargement :
       - Lorsque l'utilisateur soumet le formulaire, une animation de chargement s'affiche tout en bas pour indiquer que le traitement est en cours.
  
## HOW_TO_RUN
### Résumé des Étapes :

   - L'utilisateur saisit du texte dans un champ.
   - L'utilisateur sélectionne un style de bannière (standard, ombre, thinkertoy).
   - Lorsque l'utilisateur clique sur le bouton de soumission :
       - Une animation de chargement s'affiche.
       - Le texte est converti en art ASCII en utilisant le style de bannière choisi.
       - L'art ASCII généré est affiché à l'utilisateur.
   - L'utilisateur peut répéter le processus avec un nouveau texte ou un style de bannière différent.

### TO RUN IT :
Assurez vous d'etre dans le bon fichier, et mettez sur le terminale:
```bash
go run .
```
